# SquareSumV1-S02CG 云端验证与待测评交接

更新时间：2026-08-06（Asia/Shanghai）

## 1. 结论

S02CG 在 S02CF 基础上，将 fastPath3 非连续布局的 workspace split-K
安全覆盖范围从输出 `9～32` 扩展到 `9～64`。这是一个单行 host 路由
门限改动，不改变 kernel，也不包含隐藏 Case 信息。

Ascend 910B4、CANN 社区版 8.5.0 的最终验证为：

```text
新增输出 33～64 边界正确性      39/39
累计六组正确性回归             270/270
32M 大规模全 fastPath 图谱       26/26
4M 小规模全 fastPath 图谱        42/42
```

正式平台结果尚未返回，不能据公开图谱宣称已经达到
`0.30 × T_baseline = 1195.599 us`。

## 2. 根因与实现

fastPath3 处理“首尾归约、中间维保留”的布局。S02CE 已证明输出 `9～32`
时，旧的按输出分组策略会因启动核数不足而退化；S02CF 沿用了输出上限
32。公开大规模图谱发现，输出 64 的同类布局仍走低并行度路径。

S02CG 只将通用门限：

```cpp
NONCONTIGUOUS_SPLITK_MAX_OUTPUTS = 32U
```

提高到 `64U`。其余安全条件保持不变：归约行数不少于 16、连续尾段为
1024～16384、输入规模达到既有门限，并复用已经验证的 workspace
split-K 与最终合并逻辑。输出 65、归约行数 15 等布局仍回退旧路径。

## 3. 性能证据

相同 26 点、每点约 32M 元素的大规模图谱：

| 指标 | S02CF（us） | S02CG（us） | 变化 |
| --- | ---: | ---: | ---: |
| 26 点中位总和 | 7228.150 | 6068.880 | -16.04% |
| 最大单点 | 813.140 | 813.360 | +0.03% |

直接目标布局 `(64, 64, 8192), axes=(0, 2)`：

| dtype | S02CF（us） | S02CG（us） | 加速 |
| --- | ---: | ---: | ---: |
| FP16 | 549.300 | 111.910 | 4.908x |
| FP32 | 621.350 | 177.080 | 3.509x |

单独目标复验为 FP16/FP32 `112.450/200.530 us`，与完整图谱的数量级
一致。大图谱其余路径没有结构性退化；最大单点的 `0.220 us` 差异属于
测量噪声。

4M 小规模图谱再次 `42/42`，中位总和为 `3047.187 us`。该图谱存在
明显的几十微秒启动噪声，只作为回退筛查，不替代大规模吞吐证据。

## 4. 正确性覆盖

新增 13 个布局、3 种 dtype，共 39 项，覆盖：

- 输出 33、40、47、48、63、64；
- 连续尾段 1024、8192、16384；
- rank4、多维输出、keep_dims、负轴；
- FP16、BF16、FP32；
- 输出 65 和归约行数 15 的门限外回退。

随后重新执行 S02BT 69 项、S02CA 36 项、S02CB 42 项、S02CE 42 项、
S02CF 42 项和 S02CG 39 项，累计 `270/270`。
