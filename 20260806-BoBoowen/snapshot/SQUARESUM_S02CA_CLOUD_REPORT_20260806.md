# SquareSumV1-S02CA 云端验证与待测评交接

更新时间：2026-08-06（Asia/Shanghai）

## 1. 结论

S02CA 是 S02BT 的后继候选，针对 fastPath4 中大规模、窄 inner 的交错
归约增加通用 split-K 路径。它只在 inner 为 4～16、外层归约组不少于
40、输入不少于 262144 元素且输出不超过 512 时启用；inner=2 保持
S02BT 分组行路径，避免公开 A/B 中已经观察到的负收益。

最终干净构建在 Ascend 910B4、CANN 社区版 8.5.0 上通过：

```text
S02BT 自适应边界复验       69/69
33 点路径矩阵              33/33
S02CA split-K 专项边界     36/36
本轮最终复验合计          138/138
```

S02BT 已有累计门禁为 1634/1634；S02CA 没有改变未命中新路由的内核路径，
并另行完成上述 138 项最终复验。正式平台五个 Case 尚未返回，不能据代理
矩阵宣称达到目标 `1195.599 us`。

## 2. 实现

新路径同时满足：

```text
fastPath == 4
reduceMode == 0
4 <= innerElements <= 16
末级归约长度为 2、4、8、16、32 或 64
存在物理连续的保留输出维，维度不少于 8
外层归约组数不少于 40
inputElements >= 262144
outputElements <= 512
8 行分组后的 UB 输入不超过 8192 个元素
```

40 个 AIV 核按外层归约组均匀分工。每个核一次搬运 8 个物理连续输出行，
在 UB 中平方并按末级归约维做 FP32 累加，然后将该核的 FP32 partial 写入
workspace。所有核同步后，0 号核按 workspace 行顺序累加并写回最终结果。

路由仅依赖 shape、axis、dtype、物理 stride 和硬件容量，不读取输入值，
不使用 Case 编号，也不包含隐藏样例硬编码。

源码：

```text
candidates/squaresum_s02bu_strided_grouped_splitk_20260806/SquareSumV1
```

最终算子提交：`2c17660`；专项测试提交：`ad25fbd`。

## 3. 性能证据

33 点矩阵的目标布局为：

```text
shape=(64, group, 64, inner), axes=(0, 2)
group * inner = 256
FP16 / BF16 / FP32
```

| 路径（三种 dtype 合计） | S02BT（us） | S02CA（us） | 比值 |
| --- | ---: | ---: | ---: |
| inner=2（回退原路径） | 2513.948 | 2725.332 | 0.922x |
| inner=4 | 1440.856 | 1316.372 | 1.095x |
| inner=8 | 597.860 | 573.816 | 1.042x |
| inner=16 | 530.192 | 222.000 | 2.388x |
| 33 点完整矩阵 | 7045.946 | 6559.652 | 1.074x |

inner=2 最终代码没有进入 split-K；该行差异来自不同时段的整轮测量波动，
不视为算法回退证据。可以确认的结构性收益是 inner=16 的约 2.39 倍，
inner=4/8 也未出现负收益。官方隐藏布局是否包含这些路径仍需测评确认。

## 4. 正确性覆盖

新增 36 项专项覆盖：

- 外层归约组数 40、41、64、128、256；
- 末级归约长度 2、4、8、16、32、64；
- inner 4、5、7、8、15、16；
- 输出 128、256、505、510、511、512；
- rank4/rank5、多外层输出行、负轴和乱序轴；
- `keep_dims=True/False`；
- FP16、BF16、FP32。

最大 FP32 绝对误差为 `2.86102e-06`；FP16/BF16 在本组输入上均与参考
结果逐元素一致。

## 5. 淘汰分支

- 首个 40 核树终结器的 256 个输出全部错误；修复 workspace 声明后错误
  仍存在，因此未打包。
- 显式逐行 gather 后再做 UB 树归约仍错误，说明问题不只在二维 stride；
  该分支已撤回。
- 将 64 个外层归约组改为 32 核时，33 点从 `6401.010` 退到
  `6696.498 us`，因此恢复 40 核。
- S02BZ 对 inner=2 也启用 split-K，公开 A/B 比 S02BT 慢约 4.8%；
  S02CA 将 inner=2 恢复为原分组行路径。

这些失败版本均未作为最终提交包。
