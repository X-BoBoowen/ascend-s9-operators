# 华为昇腾NPU的GCD算子优化

本项目为华为NPU实现了优化的GCD（最大公约数）算子，结合了减法和模运算以实现高性能计算。

## 关键优化技术

### 1. 向量化减法方法
主计算采用向量化减法：
- 使用硬件加速的MIN/MAX/SUB操作
- 每次处理4096个元素（TILE_SIZE）
- 当任一操作数为1时提前终止计算

### 2. 高效广播机制
算子通过两种模式处理广播：
- **快速模式**：输入形状相同时使用（无需广播）
- **慢速模式**：输入形状不同时使用（需要广播）

### 3. 分片优化
分片策略最小化内存访问开销：
- 在TilingData结构中存储张量维度
- 为广播输入优化内存访问模式

### 4. 概率跳过机制
使用标量GCD计算辗转相减法在50次计算后仍为得到结果的数据，这里需要通过统计分析确定最佳的次数。

## 实现细节
向量化实现使用：
- AscendC硬件指令（MIN, MAX, SUB）
- 针对16位和32位整数的特殊处理
- 条件执行的掩码操作（Select的使用）

## 后续优化方法

可以使用Stein's Algorithm（二进制GCD）替代本实现中使用的辗转相减法，但是条件判断会变多，向量实现更为复杂。
