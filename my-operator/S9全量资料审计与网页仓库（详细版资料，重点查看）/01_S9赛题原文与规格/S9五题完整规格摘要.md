# S9 五题完整规格摘要

来源：S9 工作簿、官方测试脚本、PyTorch 2.5 页面。

## Concat

- 完整规格：Tensor[]；dim 默认 0；float32/float16/int32/int8；任意 rank 和合法 dim；除拼接轴外形状一致；允许 1D 空张量和长度 0 分片；非对齐。
- 当前实现：仅 FP16，kernel 把最后一维当拼接轴；host 虽按 dim 推输出 shape，但 tiling/kernel 不使用 dim；地址数组只容纳 16 个输入。
- 风险：直接解释 Case1 通过、Case2–5 Run failed。隐藏用例只要改变 dtype、rank、dim、输入数或尾块就可能失败。
- 下一步：通用 N-D fallback + last-axis 快路径；动态输入数；0 长度输入；尾块 DataCopyPad；多 dtype。

## Greater

- 完整规格：self/other；float32/bfloat16/float16/int32/int8；输出 bool；支持广播；覆盖 inf、-inf、NaN。
- 当前实现：仅 FP16 等形；输出 shape 直接等于 self；整张量进 UB；以 SubRelu/Mins/Cast 代替 Compare。
- 风险：广播不成立，较大张量 UB 超限；NaN/Inf、溢出和非对齐都可能产生错误或运行失败。
- 下一步：广播步长映射；原生比较语义；分块；多 dtype；特殊值回归。

## IndexAdd

- 完整规格：self/index/source；dim 默认 0；index 为 int32 一维向量；source[dim]=len(index)，其他维匹配 self；重复 index 必须累加；输出从 self 开始。
- 当前实现：忽略 self；仅 int8、二维、dim=0；空 index 有 blockDim=0 风险；source/out 非对齐复制未覆盖。
- 风险：当前实现不满足基础定义；重复索引、任意维度和其他 dtype 均不可靠。
- 下一步：先复制 self；重复 index 正确累加；任意 rank/dim；冲突策略；多 dtype 和尾块。

## Transpose

- 完整规格：input + dims 列表；float32/float16/int32/int8；最高 6D 任意排列；非对齐。
- 当前实现：仅 FP16 二维交换；忽略 dims；仅处理 16×16 整块；任一维小于 16 时 totalTiles=0。
- 风险：任意排列、尾块、非二维都不支持，且小尺寸存在除零/零核风险。
- 下一步：通用坐标映射；尾块；2D 16×16 快路径；任意 dims/rank/dtype。

## SquareSumV1

- 完整规格：square 后 sum；axis 为 list_int；keep_dims 默认 false；float16/bfloat16/float32；单轴/多轴/负轴；非对齐。
- 当前实现：仅 FP16 最后一轴；输出 shape 强制保留最后一维；忽略 axis/keep_dims；FP16 先平方再转 FP32。
- 风险：多轴、非末轴、keep_dims=false、BF16/FP32 均不完整；FP16 平方会先溢出或损失精度。
- 下一步：轴归一化；FP32 中间计算；多轴分阶段或通用回退；正确输出 shape。
